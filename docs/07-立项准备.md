## 1. 项目脚手架（SC1-SC10 决策）

### 1.1 Monorepo 结构

```
Urchin-Browser/
├─ apps/
│  └─ desktop/                    # 主 Electron 应用
│     ├─ src/
│     │  ├─ main/                 # 主进程入口
│     │  ├─ renderer/             # 渲染进程入口（React）
│     │  └─ preload/              # preload 脚本
│     ├─ electron-builder.yml
│     └─ vite.config.ts           # 单配置文件多入口（SC1 决策）
├─ packages/
│  ├─ ipc-contract/               # M17 进程间通信契约（zod schema + registerHandler + typedInvoke）
│  ├─ ai-provider-contract/       # M12 AI Provider 契约 API
│  ├─ ai-extension/               # M13 AI Side Panel React 组件
│  ├─ browser-host/               # Host API 契约接口
│  ├─ chrome-types/               # chrome.* API 类型定义（预加载用）
│  ├─ logger/                     # 结构化日志
│  ├─ provider-sdk/               # Provider 子进程入口运行器
│  └─ summary-agent/              # 摘要 Agent 模块
├─ docs/                          # 设计文档体系
├─ agents.md                      # 通用模板（待适配）
├─ pnpm-workspace.yaml
├─ tsconfig.base.json
├─ package.json
├─ CHANGELOG.md
└─ README.md
```

### 1.2 构建策略（SC1-SC2 决策）

| 目标 | 入口 | 构建产物 | Vite 配置 |
|---|---|---|---|
| main | `apps/desktop/src/main/index.ts` | CommonJS + Node | `build.rollupOptions.input` 多入口 |
| renderer | `apps/desktop/src/renderer/index.html` | ESM + 浏览器环境 | 默认 HTML 入口 |
| preload | `apps/desktop/src/preload/*.ts` | CommonJS + Node | 独立 rollup 入口 |
| utility | `apps/desktop/src/main/orchestrator/electron-factory.ts` | CommonJS + Node | 随主进程打包，运行时 fork |

**SC1 决策落地**：单 `vite.config.ts` 文件，通过 `build.rollupOptions.input` 配置多入口。

### 1.5 CI 平台（SC10 决策）

**GitHub Actions**，W1 初始化时配置流水线：

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  verify:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with: { node-version: '22' }
      - run: pnpm install
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test --coverage
      - run: pnpm e2e
```

## 4. 决策记录（SC1-SC10）

| ID | 决策 | 选定方案 | 否决方案理由 |
|---|---|---|---|
| SC1 | Vite 配置策略 | 单 `vite.config.ts` 多入口 | 每个目标独立配置维护复杂 |
| SC2 | Main 进程构建 | Vite 打包 main → dist/main/index.js | 直接运行 ts-node 生产环境不可行 |
| SC3 | Electron 版本 | 最新稳定版 | 旧版本缺 utilityProcess 改进 |
| SC4 | 包管理 | pnpm workspace | npm workspace 不够严格 |
| SC5 | TypeScript 严格模式 | `strict: true` + `noUncheckedIndexedAccess` | 仅 `strict: true` 安全性不足 |
| SC6 | 路径别名 | workspace 包名（`@urchin/*`） | 相对路径重构麻烦 |
| SC7 | ESLint 配置 | TS-ESLint + Prettier + React 插件 | 仅 TS-ESLint 漏检 React 规则 |
| SC8 | pre-commit hook | Husky + lint-staged（ESLint + tsc + prettier） | 仅 lint-staged 无类型检查 |
| SC9 | 提交规范 | `@commitlint/config-conventional` | 无约束提交信息不规范 |
| SC10 | CI 平台 | GitHub Actions | 与远程仓库一致，无额外配置成本 |

## 5. 开发环境搭建步骤

### 5.1 前置条件

| 工具 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 22（`node -v` 验证） | 在 `package.json` 中指定 `engines.node >= 22` |
| pnpm | ≥ 9（`pnpm -v` 验证） | 在 `package.json` 中指定 `engines.pnpm >= 9` |
| Git | 最新版本 | 克隆仓库与提交管理 |
| Windows 构建工具 | Visual Studio 2022 Build Tools 或 `pnpm add -g windows-build-tools` | better-sqlite3 等原生模块编译需要 |

### 5.2 搭建步骤

```bash
# 1. 克隆仓库
git clone https://github.com/sgobiorodolfo170-ai/Urchin-Browser.git
cd Urchin-Browser

# 2. 安装依赖
pnpm install

# 3. 验证环境
pnpm typecheck      # TypeScript 类型检查通过
pnpm lint           # ESLint 检查通过
pnpm test           # 单元测试通过
pnpm dev            # 启动 Electron 开发模式，空窗口正常显示

# 4. 验证 E2E（可选，首次需下载 Playwright 浏览器）
pnpm exec playwright install
pnpm e2e            # E2E 测试通过
```

### 5.3 常见问题

| 问题 | 解决方案 |
|---|---|
| `better-sqlite3` 编译失败 | 安装 Visual Studio 2022 Build Tools，确保包含「C++ 生成工具」工作负载 |
| `pnpm dev` 启动后窗口空白 | 检查 Vite 是否正常编译 Renderer 入口，`vite.config.ts` 中 `build.rollupOptions.input` 路径是否正确 |
| ESLint 报大量错误 | 确认 `eslint.config.js` 与 `tsconfig.json` 中的路径别名一致 |
| Playwright E2E 启动 Electron 失败 | 确认 `playwright.config.ts` 中 `electron` 入口路径与 `electron-builder.yml` 一致 |
