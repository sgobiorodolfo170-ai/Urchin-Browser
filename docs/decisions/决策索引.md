## 决策更改流程

未来若需修改已 Accepted 的决策，按 AGENTS.md §〇.4「修改权限请求机制」：

1. **停止直接修改**，新建 ADR-XXX 标记旧 ADR 为 Superseded；
2. **说明冲突点**：哪一章程、哪一条架构性约定与项目实际情况冲突；
3. **提出修改方案**：建议调整方向、理由及潜在影响；
4. **请求用户授权**：架构性变更需用户明确确认；
5. **记录变更**：新 ADR 中标注变更原因与授权来源。
