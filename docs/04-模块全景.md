## 3. 模块依赖关系（核心链）

- M2(Tab) → M3(Navigation) → M1(Window)
- M13(Side Panel) → M14(Context Extractor) → M2(Tab 当前激活)
- M13 → M17(IPC) → M11(AI Orchestrator) → M12(Provider API / Provider Child)
- M15(DevTools Enhance) → M2(Tab) → M17
- M9(Chrome Compat) → M2 + M6 + M7（要做 chrome.tabs/history/storage 等子集，必须依赖这些数据源）
- M10(Extension Loader) → M9 + M18（权限沙箱）
- M11 → M8(Storage 存会话/上下文) → M18(敏感数据加密)
