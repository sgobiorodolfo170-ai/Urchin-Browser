# M25 邮箱模块功能规划

> 状态：已定稿 · 日期：2026-09-24 · 关联决策：[ADR-010](./decisions/ADR-010-邮箱模块选型与架构.md)（ML1-ML4）
> 约束遵循：[新模块接入约束声明](./新模块接入约束声明.md)
> 技术栈：imapflow（收）+ nodemailer v10（发）+ postal-mime（解析）+ 自建 React UI（Radix UI + Tailwind/M19）

---

## 1. 模块定位

| 项 | 值 |
|---|---|
| 模块编号 | M25 邮箱（Mail） |
| 所在进程 | main（引擎 + 存储）+ renderer（UI） |
| v0.1 范围 | 只读收信：账户配置 + INBOX 列表 + 邮件阅读 + IDLE 推送 |
| 依赖模块 | M8（Storage）、M17（IPC）、M18（Permission/Sandbox）、M19（Theme） |
| 被依赖模块 | 无（其他模块不依赖邮箱） |
| 入口 | 左侧栏 pi 按钮下方新增「邮箱」按钮 → `urchin://mail` 标签页 |

## 2. 架构设计

### 2.1 进程模型

```
┌─ 渲染进程 (renderer) ──────────────────────────────────┐
│  MailView (React + Radix UI + Tailwind/M19)            │
│    ├─ 账户设置表单（AccountSetup）                      │
│    ├─ 文件夹列表（FolderList）                          │
│    ├─ 邮件列表（MessageList，虚拟滚动）                 │
│    ├─ 邮件详情（MessageDetail，postal-mime 解析）       │
│    └─ ↕ window.urchin.invoke('mail.*')  (M17 IPC)     │
└────────────────────────────────────────────────────────┘
                         ↕ zod 双向校验
┌─ 主进程 (main) ────────────────────────────────────────┐
│  MailManager (业务编排)                                 │
│    ├─ ImapClient (imapflow)                            │
│    │    ├─ connect / fetch / search / IDLE             │
│    │    └─ OAuth2 (Gmail/M365，v0.3)                   │
│    ├─ SmtpTransport (nodemailer v10，v0.2)             │
│    ├─ MailStorage (SQLite via M8)                      │
│    │    ├─ accounts 表（账户配置，密码走 safeStorage）   │
│    │    ├─ folders 表（文件夹缓存）                     │
│    │    └─ messages 表（邮件头缓存 + UID 追踪）         │
│    └─ MailEventBridge (IDLE → IPC event → 渲染层推送)  │
└────────────────────────────────────────────────────────┘
```

### 2.2 失败隔离设计

- IMAP 连接失败 → 邮箱标签页显示错误状态，浏览器其他标签页正常
- 邮箱模块异常 → IPC handler 返回 `IpcError`，不传播到 Tab Manager
- SQLite mail_* 表损坏 → 迁移事务回滚，不影响 windows/tabs/bookmarks/history 表
- 依赖加载失败 → 懒加载（dynamic import），不阻塞应用启动

## 4. 存储设计

### 4.1 迁移方案

在 `apps/desktop/src/main/storage/migrations.ts` 的 `MIGRATIONS_MAIN` 数组追加 version 2（不修改 version 1）：

```sql
-- M25 邮箱模块 · version 2
CREATE TABLE IF NOT EXISTS mail_accounts (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  imap_host TEXT NOT NULL,
  imap_port INTEGER NOT NULL,
  imap_secure INTEGER NOT NULL DEFAULT 1,
  smtp_host TEXT,
  smtp_port INTEGER,
  smtp_secure INTEGER,
  created_at INTEGER NOT NULL
  -- password 不存此表，存 safeStorage（key = mail-account:<id>:password）
);

CREATE TABLE IF NOT EXISTS mail_folders (
  account_id TEXT NOT NULL REFERENCES mail_accounts(id) ON DELETE CASCADE,
  path TEXT NOT NULL,
  name TEXT NOT NULL,
  delimiter TEXT NOT NULL DEFAULT '/',
  flags TEXT NOT NULL DEFAULT '[]',
  exists INTEGER NOT NULL DEFAULT 0,
  unseen INTEGER NOT NULL DEFAULT 0,
  last_synced_at INTEGER,
  PRIMARY KEY (account_id, path)
);

CREATE TABLE IF NOT EXISTS mail_messages (
  account_id TEXT NOT NULL REFERENCES mail_accounts(id) ON DELETE CASCADE,
  folder TEXT NOT NULL,
  uid INTEGER NOT NULL,
  subject TEXT,
  from_addr TEXT,
  to_addrs TEXT,
  date TEXT,
  size INTEGER,
  flags TEXT NOT NULL DEFAULT '[]',
  fetched_at INTEGER,
  PRIMARY KEY (account_id, folder, uid)
);
CREATE INDEX IF NOT EXISTS idx_mail_messages_folder
  ON mail_messages(account_id, folder, date DESC);
```

### 4.2 隔离保证

- 新表以 `mail_` 前缀命名，与 `windows`/`tabs`/`bookmarks`/`history`/`settings` 无外键关联
- 账户级联删除（`ON DELETE CASCADE`）仅在 `mail_` 表间生效，不影响其他表
- 迁移事务失败时回滚，不影响 version 1 已建表

### 4.3 凭据安全

- IMAP/SMTP 密码 → `safeStorage.encryptString()` 加密后存内存索引（不落 SQLite，与 M12 Provider API Key 同一模式）
- safeStorage key 命名：`mail-account:<accountId>:password`
- OAuth2 access_token / refresh_token（v0.3）→ 同走 safeStorage
- **日志不得含密码**（AGENTS.md §六 项目特化审查点）

## 9. 安全审查清单

| 项 | 措施 | 依据 |
|----|------|------|
| 密码存储 | safeStorage（Windows DPAPI）加密，不落 SQLite 明文 | §六 项目特化审查点 |
| 日志脱敏 | 密码/token 不入日志；邮件正文 INFO+ 不记录 | §六 隐私审查点 |
| IPC 校验 | 所有 `mail.*` 通道 zod 双向校验 | §六 跨进程边界 |
| 进程隔离 | IMAP/SMTP 网络 IO 仅在主进程 | §六 进程隔离 |
| 可序列化 | Zustand store 不含 Map/Set/Function | §六 可序列化 |
| 渲染安全 | 邮件 HTML 正文在 sandbox 渲染（iframe sandbox 或 DOMPurify） | 防 XSS |
| 连接超时 | IMAP 连接/auth 超时 30s，IDLE 心跳 29min | 防 hang |
