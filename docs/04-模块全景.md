## 3. 模块依赖关系（核心链）

- M2(Tab) → M3(Navigation) → M1(Window)
- M13(Side Panel) → M14(Context Extractor) → M2(Tab 当前激活)
- M13 → M17(IPC) → M11(AI Orchestrator) → M12(Provider API / Provider Child)
- M15(DevTools Enhance) → M2(Tab) → M17
- M9(Chrome Compat) → M2 + M6 + M7（要做 chrome.tabs/history/storage 等子集，必须依赖这些数据源）
- M10(Extension Loader) → M9 + M18（权限沙箱）
- M11 → M8(Storage 存会话/上下文) → M18(敏感数据加密)

## 4. v0.1 分波次交付计划（6-8 周）

| Wave | 工期 | 模块 | 验收信号（可机器判定） |
|---|---|---|---|
| W1 | 1 周 | M1 + M2 + M3 + M17 + M18 | 打开窗口、多标签、导航 URL、关闭；IPC 类型化；sandbox+contextIsolation 开 |
| W2 | 1 周 | M4 + M5 + M6 + M7 + M10-lite + M19 + M23 基础 | 地址栏输入 + 历史/书签/设置 UI 可用；扩展加载与 manifest 解析（M10-lite）；下载进度/暂停/取消；基础主题切换 |
| W3 | 1.5 周 | M8 + M11 + M12 + M17 token 直通 | SQLite 持久化；Orchestrator fork；Provider API 契约；token 流能从 Provider Child 经 Orchestrator 经 Main 中转到达 Side Panel |
| W4 | 1.5 周 | M13 + M14 demo + M15 demo | 1 个官方 Provider（OpenAI 兼容）接入；Side Panel 摘要当前页面正文；DevTools 增强 demo |
| W5 | 1 周 | 第三方 Provider 加载 + UI warning 流程 | 用户能加载本地路径/npm 包的 Provider；版本协商失败有清晰错误提示；crash 后 UI 正确降级 |
| W6 | 1 周 | 收口 + 测试 + CI | 单测覆盖率达标；E2E 关键路径跑通；pre-commit hook 启用；GitHub Actions 流水线绿 |
| W7 | 0.5-1 周 | 体验调优 + 文档完善 | 启动 ≤3s；内存 ≤500MB（10 标签）；CHANGELOG 与 README 完善 |
| W8 | 0.5 周 | 发布准备 | electron-builder 打 Windows 安装包；签名（如有证书）；release notes |
