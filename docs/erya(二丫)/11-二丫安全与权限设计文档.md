# 11 二丫安全与权限设计文档

> 来源：[ChatGPT Pages 原文](https://chatgpt.com/space/page_d0d486444dec81918fff047804c7e5c5) · 本地落盘：2026-11-17。初次落盘保留来源稿；2026-11-17本地增量纳入dsh-pet借鉴要求，来源与取舍见00。以下仍为待实施方案，不代表功能已实现；Pages来源稿未同步本地增量；v0.6全能力补充见13。

二丫的权限设计保证用户能看清它可以读取什么、改变什么、把什么发送给模型，以及授权何时结束。安全边界由执行程序强制检查，不能依赖模型“记住规则”。本方案面向单机个人使用的首版，保留工作区与档案隔离，为后续模块扩展提供统一规则。

版本：v0.6 评审草案，2026-11-17。新增权限网关、审批票据和测试要求均为拟开发内容。关联 ER-003、004、007、008、009、010、011、012、013、014、015、016、017、018。

## 保护对象与现有缺口

保护对象包括浏览内容、历史与书签、笔记和本地文件、邮箱数据、模型凭据、长期记忆、授权记录以及用户已有的浏览器操作结果。威胁来源包括恶意网页、被污染的文档或记忆、模型错误、第三方Provider、被误用的内部IPC、并发任务和旧备份。

现有sandbox、contextIsolation和preload提供进程边界，但不能据此认定二丫已有细粒度授权。当前 `registerHandler` 统一做schema与超时；`page.extract` 按tabId查找页面；preload受信判断包含 `file:` 与 `http://localhost`。新增二丫需要精确校验调用窗口、frame、载入页面与工作区，不能仅按协议或“本机地址”授予审批能力。

## 四档权限与独立授权维度

| 档位        | 允许行为                         | 限制                                 |
| ----------- | -------------------------------- | ------------------------------------ |
| L0 对话     | 使用用户主动提交的输入           | 不自动读取页面或其他模块             |
| L1 范围读取 | 读取明确选择的资源               | 不写入；不代表允许云端外发           |
| L2 确认执行 | 对具体改动逐次确认后执行         | 确认绑定对象和内容，不能复用于新动作 |
| L3 有限自主 | 限时、限对象、限额度内低风险执行 | 首版后开放；高风险仍逐次确认         |

建议初始L0，首版只开放L0至L2。等级是帮助用户理解的预设，实际许可由具体策略决定。允许读取、允许写入、允许云端外发、允许长期记忆和允许主动提醒分别设置，任意一个开关不能代替其他许可。

授权对象Grant至少包含档案、工作区、工具集合、资源集合、操作类别、等级、次数与费用限额、到期时间、撤销时间和版本。空资源集合表示没有权限，不表示全部。跨工作区需要明确新增授权；用户主动选择的档案级偏好才可跨工作区使用。

资源授权尽量绑定稳定ID和版本。网页还绑定标签、导航版本、实际origin与frame；同一标签导航到新站点需重新判断。文件授权解析规范路径并限制真实目标，防止相对路径穿越、符号链接与目录替换绕过。站点权限不采用容易误匹配的字符串前缀。

## 操作风险与确认内容

| 操作类别           | 例子                             | 建议默认                               |
| ------------------ | -------------------------------- | -------------------------------------- |
| 范围内读取         | 提取用户选定网页                 | L1及以上，检查数据范围                 |
| 可恢复本地写入     | 新建书签、创建笔记               | L2逐次确认；后续L3可在限定范围自动执行 |
| 影响他人或外部账户 | 发邮件、公开发布、提交表单       | 每次确认收件人、内容、目标账户         |
| 财务或不可恢复动作 | 付款、永久删除、覆盖无备份文件   | 每次确认具体对象与后果，首版不接入     |
| 安全与执行环境变化 | 修改权限、安装执行程序、读取凭据 | 每次单独确认，首版不开放通用能力       |

确认卡展示动作、目标、内容预览、受影响条数、数据外发范围、费用上限、可撤销性与有效期。按钮应写“创建这条笔记”等具体动作，避免笼统“继续”。批量确认只能覆盖列出的固定集合，不能在确认后静默加入新对象。

批准票据绑定 `taskId/stepId/actorId/workspaceId/argsHash/planRevision/resourceRevision/grantRevision/expiresAt`，执行后记录 `consumedAt`。票据由可信界面经主进程签发或存储为不透明引用，模型不得构造；规范化参数摘要覆盖操作目标与实际写入内容。

## 执行端强制校验

1. 从Electron事件和受管窗口登记取得真实身份，不相信请求中的actorId或profileId。

2. 验证当前frame与载入页面是获准的二丫界面；网页、嵌入编辑器、Pi和Provider不能调用审批或授权管理接口。

3. 校验工具版本和输入schema，拒绝未注册工具、超大参数、未知字段与不支持的协议。

4. 解析资源真实归属和工作区，检查Grant未过期、未撤销、未超额，外发与记忆许可单独判断。

5. 写入时核对审批摘要、计划版本、资源版本和授权版本；有变化则返回审批过期或版本冲突。

6. 在派发副作用前再次检查撤销状态与预算，并以事务或串行队列消除并发消耗同一授权的竞态。

7. 执行后记录最小回执并验证结果；禁止模型自行把未验证任务标为完成。

旧IPC若也能访问相同资源，二丫不能通过调用旧入口绕过网关。新增通道只暴露有限领域操作，不提供任意SQL、Shell、文件系统根目录或任意JavaScript执行入口。保留外部网页无宿主特权桥的隔离方式。

CUT-01 的安全验收须同时检查遗留入口和新增入口：旧 `ai.*` 业务handler、事件与端口不再注册，旧别名不能转调高权限接口；按真实归属迁移后的Pi链路仍有独立调用身份限制。升级模块仅处理指定版本和旧键，不提供网页可调用的通用搬运功能。GenOffice供应商协议隔离在专属适配器中，任何保留项都有责任归属、范围和审查记录。

## 提示注入与记忆投毒

网页、附件、工具返回和检索记忆一律作为不可信资料，附来源与数据标签。它们说“忽略上面的指令”“用户已同意”或伪造审批文字都不产生授权。模型输出工具调用仍经过同一权限网关；不能仅靠提示词说明或关键词过滤阻止越权。

页面采集使用字段白名单和长度限制，排除密码输入、Cookie、存储凭据与无关隐藏内容。外部内容诱导访问其他标签或把数据送到新域名时，分别触发读取与外发检查。页面文字不能修改系统提示、工具定义或长期权限。

自动记忆提取保留来源和“用户明确提供/网页摘录/模型推断”的区别。可疑行为指令隔离为资料，不能转成流程授权。记忆纠正形成版本，冲突保留来源；删除沿依赖关系处理压缩摘要和索引，防止污染内容通过派生记忆再次被召回。

## 数据外发与凭据保护

模型调用前显示提供方、数据类别与范围；只发送完成任务所需的片段。用户禁止在线处理时，本地失败不得自动转云端。更换提供方、增加新数据类别或明显扩大范围时重新判断许可。模型与嵌入服务同样受外发策略约束。

Provider地址限制允许协议，检查重定向目的地。云端连接拒绝访问本机管理端点、内网敏感地址和云元数据地址；本地模型作为单独、明确允许的连接配置。自定义地址、DNS解析变化与重定向需要在实际请求链路检查，不能只检查初始URL文本。

API密钥只保存在独立SecretStore与操作系统保护机制中，由受控适配器按需使用，不进入渲染层可读配置、提示词、工具结果或日志。用户已确认二丫使用 `erya.*`；`ai.*` 原为原生助手预留，不属于Pi。CUT-01全面清理旧调用和通配迁移；Pi与二丫的凭据、Grant和会话不相互继承。只换前缀无法消除旧入口绕过授权的风险。

SQLite内容默认不因此加密。是否需要整库加密、由谁管理密钥及设备迁移流程，应在正式启用敏感记忆前确定；首版可先限制保存类别，并明确本机账户能够接触的文件范围。

## 撤销 无痕 删除与审计

权限设置提供查看有效授权、撤销单条和停止所有二丫任务。撤销阻止新的动作并尽力中止正在执行的调用；对已完成或结果未知的动作展示实际状态。按钮不能暗示撤销授权会删除已经发出的邮件或云端已经收到的输入。

无痕模式不持久保存正文、长期记忆、任务快照或可识别的页面活动记录。必要错误计数只保留脱敏类型；在线调用的数据保留仍取决于提供方合同与配置，需要单独说明。

审计记录仅包含时间、任务与步骤ID、工具和策略版本、授权依据、风险、结果码与脱敏回执。默认日志不记录完整网址、页面标题正文、收件人或模型凭据；诊断导出由用户预览和选择。审计与业务内容分别设保留期，不以“需要审计”为由永久保存所有输入。

删除记忆立即退出检索，随后清理源记录、向量、缓存及依赖摘要。磁盘页、WAL和备份按既定期限清理，不能承诺SSD立即物理擦除。备份恢复需合并备份之外的最新删除台账；台账缺失时暂停旧记忆导入，避免把无法保证的恢复说成安全恢复。

## 新接入模块的权限细化

ER-013—016使用同一网关，但资源范围按模块实际归属校验。档案级速记/日历不因任务workspaceId自动隔离；INT-00显式显示全局资源范围，绑定profile+领域+对象。资源归属不明时拒绝；工作区专属化需要独立迁移，不从UI位置推断。

| 数据与动作     | 最小授权                         | 必须检查                                                          |
| -------------- | -------------------------------- | ----------------------------------------------------------------- |
| 笔记与任务读取 | 笔记本/对象/选区                 | 同名ID区分，不读取整本未选内容                                    |
| 笔记任务写入   | L2逐项差异                       | 目标revision、状态、操作键；禁止模型覆盖notebook.state            |
| 画布           | 选定便签；媒体另授权             | 文字与坐标分开审批；文件路径不授予读取权限                        |
| 日历读/找空闲  | 明确日历ID和时间范围             | 空授权不变全部启用日历；覆盖不足明确说明                          |
| 日历改/软删    | L2含日期/时区/提醒/关联/重复范围 | expectedVersion、审批后改参失效；不自动重排冲突对象               |
| 邮件读取       | 账号/文件夹/选定邮件             | UIDVALIDITY与身份变化、缓存时效；不自动标已读或抓取远程图片       |
| 草稿与发送     | 保存草稿L2；发送高风险逐次确认   | 账号、To/CC/BCC、最终正文、附件内容摘要、草稿版本；凭据主进程使用 |
| 跨模块来源     | 源读与各目标写分别授权           | 引用解析二次检查权限；失效不能打开其他对象                        |

邮件正文、日程描述、便签和笔记均为不可信资料，不能授权调用其他模块。日程参会者不触发邀请；创建本地日程不意味着获准发信。新增工具不得扩大原日历主窗口sender白名单，后台运行进程经网关调用领域服务。

本地读取、云端外发、长期记忆和主动建议独立开关；会议地点/参会者/邮件正文也纳入敏感数据分类。普通日志不记邮件主题、地址、正文、附件路径及日程细节；MAIL-02包含现有发信日志脱敏。发送未知保留最小对账信息，不自动重试；撤权后停止新步骤，不能声称撤回已发送邮件。

GenOffice、DeepSeek Harness、Pi联动仅远期留痕；当前不授予跨工作台桥接权限。CUT-01原入口封堵和已有功能回归继续验收。

## 网页诊断的权限边界

ER-017/018独立校验“目标、类型、时间与容量”。手动输入报错不授权二丫读取网页或监视剪贴板；打开F12也不授予采集、云端外发、记忆和主动巡查。L1只读指定网页诊断，L2确认隔离副本预览；L3不自动获得CDP全权。所有数据来源均可能含网页注入指令，日志与DOM只能作为资料。

主进程拒绝跨档案、跨工作区、任意webContentsId、内部壳与DevTools前端目标；不向普通网页开放preload/CDP，不新增生产全局调试端口。原生工具的人工Console可执行表达式，不代表二丫拥有Runtime.evaluate。清Cookie/存储、改代理/权限、断点暂停、任意JS、重放请求、真实页面点击提交和工程修改均不由诊断授权覆盖。

Console可能打印令牌与用户内容；网络URL路径/参数也可能带密钥，不能仅删除Authorization就称已脱敏。原始字段先过滤再入缓冲，仅保留必要摘要；无法安全裁剪时丢弃并报告。外发前展示服务商与数据类别，正文/截图/DOM/文件各自最小范围授权，脱敏不替代外发许可。密码字段、输入值、Cookie、认证头与存储值默认排除，不通过读取对象getter或请求体补齐。

采集状态与停止入口始终可见；导航、目标销毁、撤权或detach使会话失效，释放本次租约，不争抢连接或关闭原生F12。新服务需与剪藏现有CDP使用协调，不能detach不属于自己的会话。隔离副本禁脚本/外联/登录态并阻止危险CSS及可发请求的资源引用；副本无法安全构造时拒绝预览，不能降级在原网页直接注入。

诊断证据默认临时保存，不自动进入长期记忆或全量遥测。DT-06只取二丫自身与共用Provider层必要元数据，不穿透Pi/Harness/GenOffice会话。普通日志只记内部标识、计数、阶段与裁剪错误码，不记URL、Console文本、CSS或请求内容。

## 记忆扩展 人设与通知补充边界（v0.5）

记忆检索提供方仅接收当前获准范围内的最小查询与证据需求；返回值按10校验，不授予改写系统提示、工具、历史身份或用户原始要求的能力。外部记忆和embedding同样受外发策略约束。失败降级只能减少上下文，不能换成更宽数据范围或未获准云端服务。首版不启用第三方自动捕获聊天。

删除/纠正后，尚未发给模型的旧检索缓存和后台提交均按07的epoch、来源版本与许可重检；已发出的网络数据不能声称立即撤回。远端在途写入须对账和清理，未确认前不显示远端删除完成。无痕任务不读长期记忆，不创建持久记忆任务；后台错误也不记录输入正文。墓碑、在途任务和备份恢复均属于删除验收范围。

用户可配置人设只影响表达，不覆盖安全规则或建立权限。模型可选的形象动作仅限无业务副作用的表现白名单，未知ID忽略；动作解析路径与工具执行路径隔离。素材包只包含经过校验的资源与声明式映射，不能携带可执行脚本、任意远程URL、模型密钥或默认外发设置。未来复制上游代码或素材前逐项核查来源和许可，仓库MIT声明不自动证明每个角色、字体与生成素材可再分发。

任务通知默认不包含网页标题、URL、邮件/笔记正文或收件人，不把系统锁屏当作私密展示区域。主进程统一检查通知许可、任务可见性、勿扰和事件时效；多窗口/重启重放去重。点击时再校验真实身份与目标，任务被删除或权限失效则拒绝；不能携带审批票据或在点击时直接写入。主动建议、任务通知、声音和录音分别控制；通知许可不授权扫描页面、麦克风或后台新任务。

仍沿用可信IPC与主进程网关。参考项目的本机HTTP、独立桌面令牌注入及Cordis服务属于其运行模式，不构成二丫鉴权方案；本轮不增加端口或放宽网页sender边界。

## 安全验收与发布条件

独立反例集覆盖：跨档案/工作区读取、伪造sender或审批、过期与撤销票据、确认后改参、标签导航后复用授权、同时消费票据、路径穿越、恶意网页诱导外发、本地转云端、Pi权限串用、记忆投毒和删除后恢复。每例检查实际资源变化与网络请求，不能只断言界面提示。

规定的越权阻断用例必须全部通过，任何一个失败都阻止对应能力发布；普通任务成功率高不能抵消越权失败。发现问题时关闭相关工具或回退版本，保留最小诊断依据，由用户决定是否重新授权。此门槛只证明已测范围，不等于现实环境永不出错。

## 全能力安全边界补充（v0.6）

[13 全能力接入设计](./13-二丫全能力接入设计.md)定义的全能力是受控接入，不授予任意IPC、Node、Shell、JS或CDP。原生领域适配保持sender与真实资源身份；W批只限获准origin/frame/文档及控件，导航授权不包含站点写入。click风险由实际后果和可信站点策略判定，不由工具名或模型自报等级判定；未知副作用先暂停确认。

输入、上传、剪贴板、屏幕内容读取及模型外发分别授权。密码/登录/支付/系统确认交给用户或可信秘密代理，不写入模型、事件、日志、记忆和普通截图。验证码不自动绕过，接管恢复重查账号与目标；页面文本不能制造hand-off完成或审批票据。导航重定向、新标签与frame跨域先检查新范围，不自动追随。

settings通用工具只允许已登记普通键；notebook.state、密钥、授权记录及供应商配置不透传写入。工作台桥接不共享最高权限/会话数据库，供应商桩能力不可宣称可执行。系统安装、数据迁移、导入Cookie、文件关联或退出涉及影响预览、恢复点与可信确认；仅打开系统设置不算自动执行完成。

全局覆盖报告公开manual-only/unsupported/unknown，拒绝内部高权限入口的测试不能被当作功能缺失而删除。运行中工具/适配版本变化重检计划，用户手工修改优先触发冲突；不能为提高任务成功率扩大资源范围或隐瞒人工步骤。
