# 网页剪藏功能规划（M26 Clipper）

> 状态：已定稿 · 日期：2026-11-01 · 模块：M26（main + renderer）
> 关联：[ADR-014](./decisions/ADR-014-网页剪藏模块.md) · [04-模块全景 §1](./04-模块全景.md#1-模块清单m1-m26) · [新模块接入约束声明](./新模块接入约束声明.md)

## 1. 目标与范围

### 本期
- 地址栏截图按钮后增加「剪藏（Clipper）」按钮，打开独立剪藏面板。
- 支持 Markdown / MHTML / PDF / 截图；OCR 禁用占位。
- 默认保存到 `<用户数据目录>/documents/clipper`（2026-11-06 起可经设置「数据 → 剪藏保存路径」自定义，留空用默认）。
- 设置页「剪藏」页：默认格式、快照清洗、选中优先、懒加载、文件名/属性/正文模板。
- 自动解除可解除的前端复制限制。
- 浏览器内置只读 MHTML 查看器；GenOffice Home 可打开 `.mhtml`。
- MHTML/PDF/截图默认正文清洗，可切换原页完整。

### 不做
- 登录、付费墙、验证码、DRM 绕过。
- OCR 实际识别。
- GenOffice HTML 编辑器内直接编辑/回写 MHTML（B/C 后续）。
- 多模板、URL 触发器、高亮标注、图片本地化。

## 2. 用户流程

```
地址栏「剪藏」按钮
  → 主进程打开独立面板（?view=clipper&tabId=N）
  → 面板并行拉取 clipper.config + clipper.page
  → Defuddle 抽取（选中优先可切换）
  → 用户确认文件名/格式/清洗方式
  → clipper.saveMarkdown / clipper.saveSnapshot
  → 写入 documents/clipper，面板显示路径并关闭
```

## 3. 格式与生成

| 格式 | 扩展名 | 生成方式 | 默认清洗 |
|---|---|---|---|
| Markdown | `.md` | Defuddle + 模板 + frontmatter | 总是（Defuddle） |
| MHTML | `.mhtml` | 清洗 HTML 隐藏窗口 → `savePage('MHTML')` 或原页 `savePage` | 是 |
| PDF | `.pdf` | 清洗 HTML 隐藏窗口 → `printToPDF` 或原页打印 | 是 |
| 截图 | `.png` | CDP 整页截图（`captureBeyondViewport`） | 是 |
| OCR | — | 禁用占位 | — |

- 文件名净化、唯一路径由主进程 `ClipperStore` 负责。
- 快照清洗流程：Defuddle 正文 HTML → `<base href=原URL>` → 阅读模式 CSS → 移除脚本/iframe/表单/事件属性 → 隐藏 BrowserWindow 等待图片/字体 → 导出。

## 4. 架构

### 主进程
```
main/clipper/
  panel.ts            独立面板 BrowserWindow + 几何
  page-snapshot.ts    页面快照脚本、选区、保护信号、frame 合并
  deep-extract.ts     子 frame 收集、闭 Shadow DOM CDP 兜底
  snapshot-export.ts  隐藏窗口、MHTML/PDF/截图、清洗/原页
  store.ts            文件名净化、唯一路径、Markdown 写盘
  mhtml-viewer.ts     只读 MHTML BrowserView（JS 关闭、无 preload）
  register-handlers.ts
```

### 渲染进程
```
renderer/clipper/
  clipper-panel-app.tsx  面板 UI
  draft.ts               变量/模板/frontmatter
  extract.ts             Defuddle 抽取（defuddle/full）
  clean-html.ts          清洗 HTML + 质量判定
```

### MHTML 查看器
- `FileKind='mhtml'`；`.mhtml/.mht` 进入只读查看器。
- `javascript:false`、`sandbox:true`、无 preload；禁止导航，链接新标签打开。
- 打开入口：文件关联、GenOffice Home `openPath`、文件选择器（原生 file://）。

### GenOffice 路线图
| 阶段 | 方案 | 状态 |
|---|---|---|
| A | GenOffice Home `.mhtml` → 宿主只读阅读器 | 本期 |
| B | MHTML→自包含 HTML → HTML 编辑器（保存语义待定） | 后续 |
| C | vendor/genoffice 原生 MHTML 编辑器 | 最终方向 |

## 5. IPC 契约

| 通道 | 说明 |
|---|---|
| `clipper.open` | 打开面板（tabId，仅 http/https） |
| `clipper.page` | 页面快照（HTML/选区/信号；子 frame + closed shadow 兜底） |
| `clipper.config` | 设置默认值、主题、保存目录标签 |
| `clipper.saveMarkdown` | 写 `.md` |
| `clipper.saveSnapshot` | 写 MHTML/PDF/截图（clean 需 cleanedHtml） |
| `clipper.copy` | 复制 Markdown |
| `clipper.close` | 关闭面板 |

状态栏新增 `clipDisabled` 与动作 `{type:'clip'}`。

## 6. 设置项

| 键 | 默认 | 说明 |
|---|---|---|
| `clipper.defaultFormat` | `markdown` | 默认格式 |
| `clipper.cleanSnapshot` | `true` | 快照默认清洗 |
| `clipper.selectionPriority` | `true` | Markdown 选中优先 |
| `clipper.loadLazyContent` | `false` | 快照前滚动加载 |
| `clipper.noteNameFormat` | `{{title}}` | 文件名模板 |
| `clipper.properties` | 默认 frontmatter | 属性模板 |
| `clipper.content` | `{{content}}` | 正文模板 |

变量：`title/url/author/published/date/datetime/description/site/domain/language/words/favicon/image/content/selection/noteName`。

## 7. 锁定页面自动处理

自动执行：
1. 忽略 copy/contextmenu/selectstart 与 `user-select:none`；
2. 直接抽取 DOM；遮罩/防复制浮层不影响；
3. 开放 Shadow DOM 递归；
4. 闭 Shadow DOM CDP（调试器占用时降级）；
5. 跨域 iframe 逐 frame 抽取；
6. 异常字体/私用区字符提示；
7. 可选懒加载滚动。

不执行：登录、付费墙、验证码、DRM。质量低时提示改用 MHTML/PDF/截图。

## 8. 安全与隐私

- 只接受 tabId，不接受任意路径；目录固定。
- MHTML 查看器禁用 JS、无 preload；链接禁止在本视图导航。
- 清洗快照移除脚本/iframe/表单/事件属性。
- 日志不记录页面 URL/标题/正文；只记录 tabId、格式、文件路径、字节数。
- 深度抽取不改页面持久状态；懒加载滚动后恢复滚动位置。

## 11. 风险

- Electron 43 对 file MHTML 渲染需实测；失败启用自研解析/外部打开。
- 清洗快照可能缺防盗链图片。
- 闭 Shadow DOM 与 DevTools CDP 冲突时降级。
- 超长截图受 Chromium 像素限制。
- OCR 未实现，图片/Canvas 正文只能保存视觉快照。

## 12. 复盘整改（2026-11-01，P0/P1）

| 项 | 整改 |
|---|---|
| MHTML 入口一致性 | 新增 `clipper.openMhtmlFile`；文件选择器/拖放与文件关联/GenOffice Home 全部走宿主只读查看器 |
| 选区上限 | 页面脚本与主进程双重截断（HTML 4MB / 文本 2MB） |
| 超长截图 | 按 16000px 分段保存；响应返回 `paths[] + warnings[]`，面板展示提示 |
| clean 快照 tab 解耦 | clean 模式 `tabId` 可选；original 仍必须存活 tab |
| 闭 Shadow DOM | CDP 节点树序列化替代 `DOM.getOuterHTML(shadowRoot)`，并插入 article/main 内，避免 Defuddle 丢弃 |
| 自动测试 | 新增 MHTML 查看器 E2E、图文+闭 Shadow E2E、PDF/截图 E2E |
| pi-web-host E2E | `node-pty`/`ssh2` 补入 desktop 依赖，修复 utilityProcess 运行时解析 |
