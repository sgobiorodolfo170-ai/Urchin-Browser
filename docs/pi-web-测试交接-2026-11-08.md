## 3. 结构决策（不要回退）

1. **`packages/pi-web-host/tsconfig.json` 排除 `tests/pi-server`**。
   原因：这些测试 import `src/pi-server`，tsc 会把整条闭包拉进程序，暴露上游既有的
   10 条类型缺口（见 §4 D5/D8/D9 与 request-context），使 `pnpm typecheck` 失败。
   `src/pi-server` 本来就被排除，测试沿用同一策略。
   排除项：`tests/pi-server`、`tests/pi-server-tool-shims.d.ts`、`tests/pi-server-vendored-shims.d.ts`。
2. **`eslint.config.js` 忽略 `tests/pi-server/**` 与 `tests/pi-server-*.d.ts`**。
   `projectService: true` 要求文件被 tsconfig 收录；既然按 (1) 排除，lint 也必须跳过。
   移植自带类型感知规则会大面积报上游风格问题，收益低。
3. **`eslint.config.js` 与 `.prettierignore` 忽略 `tmp/`**。
   基线 `tmp/` 里有 20MB bundle 快照，曾让 `pnpm lint` 报 1.8 万条解析错误。
4. **测试 import 风格**：`packages/pi-web-host/tests/pi-server/x.test.ts` →
   `import ... from '../../src/pi-server/x.js'`（保留 `.js`，vitest 会解析到 `.ts`）。
   前端测试 → `@urchin/pi-web-host/shared/*`（vite/vitest 别名）。
5. **测试侧 ambient 声明**（仅类型，不影响运行时）：
   `tests/pi-shims-augment.d.ts`、`tests/pi-server-tool-shims.d.ts`、
   `tests/pi-server-vendored-shims.d.ts`、`tests/pi-server/session-pipeline-shims.d.ts`。
   新增 vendored 导出时优先补 shim，不要改 `src/pi-shims.d.ts`（除非得到授权）。

  修复前 22 次 / 修复后 ≤5（20 条 2KB 噪声行）。
- **D12 destination 契约（2026-11-09）**：`extract` 的 `destination` **必填**，`""` 表示工作区根；缺失时本地与远程
  统一返回 400 + `Extract destination is required (use "" …)`，不再各自抛「Invalid path」。前端
  `FileTransferDialog` 始终传字符串（默认归档所在目录），故无前端改动。
- **`plugins.scm.status` 行为变化（D6）**：非仓库从 `{ ok:false, error }` 变为正常 status（`notRepo:true, empty:true, …`），
  因为 `scmStatus` 不再抛。全仓检索无调用方依赖旧形状，插件文档未单独承诺该错误码。

- **D13（已结案，2026-11-09）notRepo 间歇失败 = `Promise.all` 竞态，不是环境抖动**：`scmStatus` 并发跑 4 条 git，
  非仓库目录下它们的报错**并不一致**——`git status` / `git for-each-ref` 是 `fatal: not a git repository`（匹配），
  `git diff --numstat` 是 `warning: Not a git repository…`（仍匹配），而 `git diff --cached --numstat` 是
  `error: unknown option \`cached'`（**不匹配**，git 在无仓库时落入 `--no-index` 模式）。旧实现用 `Promise.all`，

  且 `scm.test.ts` 同源用例一并红）。
  **修复**：`scmStatus` 改 `Promise.allSettled`——任一 reject 命中 not-repo 即统一降级，否则抛首个真实错误；
  语义与顺序无关。回归用例连跑 5 次锁死语义，并在全量 `pnpm verify`（与失败时同负载）下复验通过。
