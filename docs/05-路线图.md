### v0.3 验收

## 3. 版本节奏的 SemVer 含义

按 [AGENTS.md §四](../agents.md) 与 [03-tech-stack](./03-技术栈.md) 版本规则：
- v0.x.y：次版本号 +1 表新功能（向下兼容）；修订号 +1 表缺陷修复
- v1.0.0：标记「公开 API 稳定」承诺——Provider API / IPC API / Chrome 兼容层 / DevTools Panel API 不再随意 breaking
- v0.x → v1.0 的跨越代表所有公开 API 冻结

## 4. 各版本间的依赖与可延期项

```
v0.1 ────► v0.2 ────► v0.3 ────► v0.4 ────► v0.5 ┄┄► v1.0
 │          │          │          │          │       │
 │          │          │          │          │       └─本地 LLM + 完整 E2E
 │          │          │          │          └─隐私拦截完整 + session restore
 │          │          │          └─跨平台 + Provider 签名
 │          │          └─自更新 + UX 完善
 │          └─扩展生态 + 隐私拦截基础
 └─MVP 最小闭环 + 扩展加载 + 强隔离
```

**可延期项**（视资源情况可延后，不阻塞下一版）：
- v0.2 完整 `chrome.cookies`（隐私敏感，可推 v0.3）
- v0.3 标签跨窗口拖拽（实现复杂，可推 v0.4）
- v0.5 Model Router（用户偏好路由，资源不足可延至 v0.6-v0.9 窗口，与契约 I OR9 对齐）
- v1.0 本地 LLM 集成（工程量大，可独立 v1.x 系列）

## 5. 风险登记册

| 风险 | 影响版本 | 概率 | 缓解策略 |
|---|---|---|---|
| Electron 主版本升级破坏 utilityProcess / BrowserView API | 所有 | 中 | 锁版本号；升级前跑完整 E2E；监控 Electron release notes |
| v0.1 工期 6-8 周超期 | v0.1 | 中 | W3/W4 是关键路径（IPC + Provider 契约 + Side Panel demo），可适当压缩 M15 DevTools demo 到 v0.2 |
| 第三方 Provider 滥用加载恶意代码 | v0.1+ | 中 | v0.1 进程级隔离兜底；v0.4 引入签名 allowlist；监控社区反馈 |
| Chrome 扩展兼容性 90% 但非 100% | v0.2+ | 高 | 文档明确「已支持 API 子集」，未支持 API 提供 polyfill 提示；UI 显示兼容性警告 |
| 本地 LLM v1.0 工程量超预期 | v1.0 | 中 | 提前在 v0.5 评估 ollama 集成 spike；必要时拆为 v1.1 |
| 测试覆盖率提升遇阻力 | v0.3+ | 中 | 渐进式阶梯以 [03-tech-stack §4](./03-技术栈.md#4-测试覆盖率适配门槛) 为单一真源（v0.1 ≥60% → v0.2 ≥65% → v0.3 ≥70% → v0.4 ≥75% → v1.0 ≥80%）；每次提升记入 CHANGELOG |
| Provider API v1 后无法演进 | v1.0+ | 低 | 保留 v2 路线——旧 Provider 在「apiVersion 兼容期」内继续工作；breaking change 走 SemVer 主版本 +1 |

## 6. 与 AGENTS.md §四版本迭代记录的衔接

每次版本发布后，按 AGENTS.md §四规范在 [CHANGELOG.md](../CHANGELOG.md) 追加一行：

```
| v0.1.0 | 2026-XX-XX | MVP 最小闭环 + per-provider 强隔离首次发布 |
```

版本号自增逻辑遵循 AGENTS.md §五：`feat` → 次版本 +1，`fix`/`refactor` → 修订 +1，破坏性 → 主版本 +1。

## 7. 未纳入 Roadmap 的远期展望

下列内容超出 v1.0 范围，作为长期愿景：
- **v1.x+**：移动端伴侣应用（与桌面端 sync conversation / bookmarks）
- **v2.x+**：Urchin 原生扩展 API（与 Chrome 兼容层并行，更类型安全、AI 原生语义）
- **v3.x+**：自主 Agent 模式——浏览器作为 Agent 的「眼睛与手」，自动浏览/操作/总结
- 桌面+移动全平台（D2 决策远期反转）
